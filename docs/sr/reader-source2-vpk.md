# Source 2 `.vpk` {#source-2-vpk}

**Исписује и извлачи** Valve-ове VPK архиве, верзије 1 и 2, укључујући подељене архиве и податке ускладиштене у фајлу директоријума. Сваки унос може се проверити према сопственом CRC-у. Ово је једини формат контејнера овде чији добављач га документује. Игре: Counter-Strike 2, Dota 2, Half-Life: Alyx и друге на Source 2.

Извор: [`vpk.py`](https://github.com/Holdi601/3DHeat-GameFiles/blob/main/heat3d_gamefiles/vpk.py).
Команде: `identify`, `list`, `extract`.

## Распоред {#layout}

```
u32 magic 0x55AA1234, u32 version (1 or 2), u32 tree size
  (version 2: 16 more header bytes; header 12 or 28 bytes)
directory tree:
  extension        "vmdl_c", then "vtex_c", ..., then ""
    path           "maps/example_map", then ""
      file name    "world_layer0", then ""
        u32 crc, u16 preload size, u16 archive index, u32 offset, u32 length, u16 0xFFFF
        [preload bytes]
```

- Три угнежђене петље, свака се завршава празним стрингом, па читач који очекује број не налази ниједан. Путање се чувају једном по групи и склапају из сва три дела. Један размак значи „нема фолдера“ или „нема екстензије“.
- Сваки запис се завршава са `0xFFFF`. То се проверава, па читач који је изгубио место стане одмах („директоријум се не чита на исправном помаку“).
- **Подељене архиве:** `pak01_dir.vpk` садржи директоријум, а подаци су у `pak01_000.vpk`, `pak01_001.vpk`... и бирају се индексом архива уноса.
- **Индекс архива `0x7FFF`** значи да су бајтови у самом фајлу директоријума, после стабла. Читач који га чита као прави индекс тражио би `pak01_32767.vpk`.
- **Предучитавање (preload):** мали фајлови се чувају цели у директоријуму. Дужина 0 онда није грешка.

## Команде {#commands}

```
python -m heat3d_gamefiles identify maps\example_map.vpk
python -m heat3d_gamefiles list maps\example_map.vpk --filter .nav
python -m heat3d_gamefiles extract maps\example_map.vpk maps/example_map.nav
```

`identify` исписује верзију, број уноса и први `.nav` фајл. `list` приказује сваки унос као `stored`, јер VPK не компресује. `extract` записује бајтове без провере CRC-а. У Python-у, `VpkArchive(path).verify(name)` упоређује бајтове уноса са CRC-ом који је директоријум забележио.

## Навигациона мрежа {#the-navigation-mesh}

Мапа испоручује своју **навигациону мрежу** (`maps/<map>.nav`) поред компајлиране геометрије. За топлотну мапу позиција играча она је много кориснија од друге две, јер навигациона мрежа *јесте* подлога по којој се може ходати, већ израчуната и хиљаду пута мања. Тест инсталиране игре проверава да се `.nav` испоручене мапе почиње Source магичним бројем навигације `CE FA ED FE`.

## Проверено {#verified}

Сваки унос узоркован кроз испоручене архиве мапа једне игре вратио се бајт-по-бајт тачан према свом CRC-у, и свака архива мапе се парсира.
Тестови инсталиране игре поново проверавају CRC на 25 насумичних уноса из сваке од до четири архиве мапа.

## Није реализовано {#not-implemented}

- Декодирање Source 2 компајлираних средстава (`.vmdl_c`, `.vtex_c`). То су бинарне структуре у блоковима сопствене врсте, исти посао као Unreal и Frostbite формати мрежа. Посебан 3DHeat CS2 алат обрађује геометрију CS2 мапа.
- Декодирање CS2 навигационе мреже. Њен формат је верзија 36 и разликује се од широко документованог Source 1 формата. Њени бајтови су структурирани, а не компресовани (ентропија 6,2, 31% нула), али само 3% њених речи се чита као координате, па распоред није очигледан и још није одгонетнут.
