# Одржавање: контролна листа за издање {#maintaining-the-release-checklist}

Пре означавања издања (`v` + број у `VERSION`), прођи кроз овај списак по реду. Он држи странице, слике и преводе верним коду.

1. **Поново генериши генерисане странице.**
   - `python tools/gen_docs_reference.py` поново исписује [Референцу команди](../cli-reference.md) из сопственог `--help` програма. `python tools/gen_docs_reference.py --check` излази са кодом 1 док је записана страница застарела.
   - `python tools/docs_diagrams.py --strings` поново црта дијаграме у `docs/assets/img/` и поново исписује `docs/assets/i18n/en.json`, списак свих ознака у дијаграмима које треба превести.
2. **Испиши шта се променило од последњег издања:**
   `git log --oneline v<last VERSION>..HEAD`. Свака нова команда, опција, поље излаза или понашање треба ред у `CHANGELOG.md` и ред у табели **Docs** с именом странице која га објашњава. Ажурирај ту страницу.
3. **Затражи независан преглед** промењених страница и слика од некога (или агента) ко их није писао, који чита као три особе: почетник који никад није користио терминал, осмогодишњак и професионалац. Дијаграми се такође проверавају: читљиви су на ширини странице, ознаке су тачне, а боје објашњене.
4. **Поправи оно што преглед нађе**, па провери да ниједан прави податак из игре није ушао: нема имена мапа, нивоа или играча, нема бројки из правих снимака или инсталација (користи замене као `<map>` или „тест ниво“).
5. **Поново преведи измењене странице.** Свака преведена страница бележи хеш енглеске странице из које је настала; странице чији се енглески извор променио поново се преводе, а с њима и ознаке дијаграма. Затим прегледај сваки језик: јасан је за иста та три читаоца, ознаке су тачне, а речи се поклапају с интерфејсом приказивача 3DHeat на том језику.
6. **Објави (push) тек уз сагласност власника.** Ништа се не шаље и не означава пре него што власник то каже.

## Преводи: команде {#translations-the-commands}

Сајт је преведен на 40 језика приказивача 3DHeat: енглески је у `docs/`, а сваки други језик у `docs/<lang>/` с истим именима фајлова. `tools/docs_i18n.py` води евиденцију:

```bash
python tools/docs_i18n.py hashes             # after any English change: record each page's hash
python tools/docs_i18n.py svg-strings        # after any picture change: the labels to translate
python tools/docs_i18n.py status             # per language: current, outdated, missing pages
python tools/docs_i18n.py todo --lang de     # the German pages to (re)translate
python tools/docs_i18n.py svg-build --lang de    # German pictures from docs/assets/i18n/svg/de.json
python tools/docs_i18n.py finish --lang de   # stamp the German pages with their English hash
python tools/docs_i18n.py check              # exit 1 when hashes or labels are stale
```

Преводи само оно што `todo` наводи: задржи Markdown, везе, код, имена фајлова и колона онако како јесу, преведи наслове и описе слика, и користи речи приказивача 3DHeat за његова дугмад и панеле (његов `src/i18n/locales/<lang>/`). Генерисане странице референце и терминалне слике остају на енглеском. На сајту застарели превод то каже и повезује енглеску страницу; недостајући пада на енглески. Језички мени у заглављу и преусмеравање почетне странице према језику прегледача долазе из `docs/_includes/`.
