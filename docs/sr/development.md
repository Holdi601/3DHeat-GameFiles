# Развој {#development}

## Распоред {#layout}

```
heat3d_gamefiles/     пакет: читачи, извози стаза, командна линија
heat3d_update/        провера издања и ажурирање (видите Ажурирања)
tests/                синтетички тестови, фикстуре и тестови над инсталираним играма
docs/                 ова документација (docs/wiki се генерише из ње)
VERSION               инсталирана верзија, упоређена с издањима на GitHub-у
requirements.txt      numpy, cryptography, lz4, Pillow, msgpack, zstandard, pytest
```

## Покретање тестова {#running-the-tests}

```
pip install -r requirements.txt
python -m pytest
```

`pytest.ini` поставља `testpaths = tests` и `-q`. Две врсте тестова су важне, из различитих разлога:

- **Синтетички тестови** праве архиве бајт по бајт и раде свуда. Они фиксирају распореде поља које су некад били погрешни: 64-битна основа `.minizip` сегмента и његово поравнање, размер блока у pak-у, u32 између два int64 у Unity заглављу, индекс `0x7FFF` у VPK-у, раздељени x нормале у Forza-и.
- **Тестови над инсталираним играма** раде над правим датотекама кад је игра на рачунару, а **прескачу се** (не падају) кад није. Они су једина ствар која хвата распоред који је тачан за мали фајл, а погрешан за велики.

| `tests/frostbite_fixtures.py` | Frostbite табеле, пакети, EBX партиције, мреже и странице терена, бајт по бајт |

## Тестови над инсталираним играма {#installed-game-tests}

[`tests/installed.py`](https://github.com/Holdi601/3DHeat-GameFiles/blob/main/tests/installed.py)
налази игре за тестове. `steam_common()` исписује `steamapps\common` сваке Steam библиотеке (укључујући Steam-ове сопствене фасцикле), а `installed(*globs)` враћа путање које одговарају било ком обрасцу под њима, рекурзивно где образац има `**`. Сваки тест одлучује шта му треба:

| Тест | Тражи | Прескаче се са |
|---|---|---|
| `test_pak.py` | `*/(*/){0..3}Content/Paks/*.pak` са **нешифрованим** индексом, до 4 | „no shipped pak on this machine“ |
| `test_unity.py` | `resources.assets` / `sharedassets0.assets` у `*/*_Data` или `*/*/*_Data` које читач прихвата, до 6 | „no Unity game on this machine“ |
| `test_frostbite.py` | `Battlefield*/**/*.toc` | „no Frostbite game on this machine“ |
| `test_frostbitelevel.py` | `Battlefield*/**/levels/**/*.toc` | „no Frostbite level on this machine“ |
| `test_vpk.py` | `Counter-Strike Global Offensive/game/csgo/maps/*.vpk`, до 6 | „Counter-Strike 2 is not installed“ |
| `test_forzatech.py` | `ForzaHorizon*/media/*.zip` | „no Forza install on this machine“ |
| `test_forzaplacement.py` | кругове FH Companion библиотеке (почетак и крај у 50 m), са највише кругова, које `find_track` поставља; или `HEAT3D_COURSE` | „no Forza install with a recorded lap library here“ |
| `test_beamng.py` | `find_install()` | „BeamNG.drive is not installed“ |
| `test_acrally.py` | `find_paks()` | „Assetto Corsa Rally is not installed“ |

Покрените тестове само једне игре, или усмерите Forza тест за ивичњаке на стазу:

```
python -m pytest tests/test_vpk.py
set HEAT3D_COURSE=%LOCALAPPDATA%\FHCompanion\laps\Example Circuit (course_0_0_to_0_0)
python -m pytest tests/test_forzaplacement.py -k kerbs
```

Тестови над инсталираним играма читају само из игара. Ништа не пишу у фасцикле игре. Излази тестова иду у привремене фасцикле pytest-а.

## Конвенције {#conventions}

- **Одбиј, не погађај.** Сваки читач подиже свој изузетак (`UnsupportedPak`, `IoStoreError`, `UnsupportedForza`, `UnsupportedUnity`, `UnsupportedFrostbite`, `UnsupportedVpk`, `BeamNGError`, `PropertyError`...) са поруком која каже шта је нађено и зашто није прочитано.
- **Провери према самом формату.** Хеш, CRC, ланац офсета, сачувана гранична кутија, вожња која лежи на тлу. Не „није се срушило“.
- **Нема кључева, нема испоручене власничке коде.** Видите [Правила и лиценце](rules-and-licences.md).
- **Поверљиви подаци остају ван.** Игрине датотеке, извози, кругови, снимци и снимци екрана никад не иду у репозиторијум. `.gitignore` их искључује по фасцикли и по врсти. Тестови користе синтетичке податке и инсталиране игре, никад садржај игре који је уписан у репозиторијум.
