# Улазни подаци круга {#lap-inputs}

**Фајл круга** је списак тачака x, y, z: где је аутомобил пролазио. Најбржи ручно прављен је CSV из [5. табела `.csv`](#5-a-csv-table) испод.

Круг извоз стазе говори **где је аутомобил возио**. Ништа друго из њега се не користи: брзина, управљање и g-силе припадају телеметријском делу 3DHeat-а. Алат чита положаје у светским метрима игре, а тамо где фајл то каже и игру и стазу.

Извор: [`lapinput.py`](https://github.com/Holdi601/3DHeat-GameFiles/blob/main/heat3d_gamefiles/lapinput.py).

## Шта прихвата `course` {#what-course-accepts}

Формат се препознаје по садржају фајла, а не по имену, осим што `.npz` и `.csv` иду по екстензији, а све остало се покушава као JSON.

### 1. `heat3d-lap` документ (било која игра) {#a-heat3d-lap-document-any-game}

Пишу га снимачи телеметрије 3DHeat-а (`heat3d_capture telemetry` ([3DHeat GameCapture](https://github.com/Holdi601/3DHeat-GameCapture))):

```json
{
  "format": "heat3d-lap",
  "game": "beamng",
  "track": "Example Stage",
  "channels": {
    "x": [12.0, 12.4, 12.9],
    "y": [3.1, 3.1, 3.2],
    "z": [-40.0, -38.7, -37.3],
    "speed": [21.0, 21.3, 21.8]
  }
}
```

- `channels.x`, `channels.y` и `channels.z` су обавезни. Редови где било која од три није коначан број се бришу. Остали канали се занемарују.
- `game` одређује извоз (видите [Команде](commands.md#which-game)).
- `track` користи Assetto Corsa Rally да прво испроба именовану деоницу.
- Осе: y је висина. Forza и AC Rally кругови користе хоризонталне осе игре онако како их снимач пише. BeamNG кругови се очекују у оквиру приказивача, `(x, z, -y)` светског BeamNG-а са Z нагоре (видите [BeamNG.drive](course-beamng.md#the-laps-frame)).

### 2. Датотека руте {#a-route-file}

Пише је `heat3d_capture route` и `heat3d_capture laps`:

```json
{
  "bounds": {"min": [0.0, 80.0, 0.0], "max": [500.0, 140.0, 500.0]},
  "positions": [[12.0, 101.2, 40.5], [12.9, 101.2, 42.0]]
}
```

`positions` је списак `[x, y, z]`. Датотека руте са `bounds` али без положаја и даље ради: њена два угла су дегенерисана линија, али користан оквир.

### 3. FH Companion фајл круга {#an-fh-companion-lap-file}

Фајлови по кругу из FH Companion-ове снимљене библиотеке:

```json
{"Lap": {"samples": [{"X": 12.0, "Y": 101.2, "Z": 40.5}, {"X": 12.9, "Y": 101.2, "Z": 42.0}]}}
```

Недостајући `X`, `Y` или `Z` чита се као 0. Фајлови су записани с ознаком редоследа бајтова, па се сав JSON чита као `utf-8-sig`.

### 4. `.npz` снимак {#a-npz-recording}

NumPy архива која садржи низ `positions` облика (n, 3).

### 5. `.csv` табела {#5-a-csv-table}

```
# {"game": "assetto-corsa-rally", "track": "Example Stage"}
time,x,y,z,speed
0.00,12.0,3.1,-40.0,21.0
0.05,12.4,3.1,-38.7,21.3
```

- Колоне под називима `x`, `y`, `z` (велика и мала слова и размаци око назива се занемарују) су обавезне. Остале колоне се занемарују.
- Редови који почињу са `#` се прескачу. Ако је **први** ред `# {json}`, читају се његови `game` и `track`.
- Редови који се не читају као бројеви се прескачу.

### 6. Фасцикла {#a-folder}

Фасцикла се претражује **рекурзивно** за `.json`, `.npz` и `.csv` фајловима, и сви се спајају у једну возану линију. Тако се чува цела снимљена стаза: FH Companion гнезди фасцикле по класи, аутомобилу, подешавању и ознаци.

- `course.json` се прескаче по имену (то су метаподаци, а не круг).
- Фајл који се не може прочитати тихо се прескаче. Један лош фајл међу стотинама не кошта остале.
- Конзола јавља колико фајлова круга је ушло (`12 laps, 18,400 samples`).
- Фасцикла добија игру коју њени фајлови именују, кад именују **само једну**. Фајл који не именује игру (FH Companion круг, `course.json`, CSV без реда описа) се не рачуна, па један од њих међу снимцима једне игре не одузима фасцикли њену игру. Фајлови који именују две различите игре су мешавина, и фасцикла не добија ниједну. Фасцикла без игре извози се као Forza, осим ако `--game` не каже друкчије.
- Ако ништа не може да се прочита: „no readable laps under <folder>“.

### 7. Име стазе {#a-course-name}

Ако аргумент није постојећи фајл или фасцикла, тражи се као име стазе у библиотеци FH Companion-а, `%LOCALAPPDATA%\FHCompanion\laps`:

1. фасцикла чије име, без суфикса ` (course_...)`, је једнако траженом (без обзира на велика и мала слова);
2. иначе једина фасцикла чије име садржи тражено.

Тако `"Example Circuit"` налази `Example Circuit (course_1200_3400_to_1175_3400)` без икога ко зна координате. Више погодака је грешка која их набраја. Стаза нађена по имену нема игру, па се извози као Forza, осим ако `--game` не каже друкчије.

## Шта прихвата `terrain --route` {#what-terrain---route-accepts}

`terrain` треба `bounds` датотеке руте (облик 2 горе), `{"min": [x, y, z], "max": [x, y, z]}`. Без `bounds` се зауставља уз поруку „<file> has no bounds; --route takes a route file with "bounds": {...}“. Фајл се чита као UTF-8, са или без ознаке редоследа бајтова, као сваки JSON круг. Ако исти фајл има и најмање 10 положаја који се могу прочитати по горњим правилима, они сужавају исецање на коридор и усмеравају детаљ.

## Како се круг користи {#how-the-lap-is-used}

| Употреба | Детаљ |
|---|---|
| назив | назив фајла, или назив фасцикле, без ` (course_...)`; постаје подразумевани назив излазног фајла |
| пређена вожња | збир размака између узастопних узорака (исписује се као `m driven`; преко фасцикле ово укључује скокове између фајлова) |
| кутија | опсег x и z проширен за `--margin`; висина се никад не ограничава |
| коридор | x и z сваког узорка, видите [Извоз стазе](course-export.md#the-corridor) |
| детаљ | удаљеност сваке постављене копије до најближег узорка, видите [Нивои детаља и буџет](detail-budget.md) |

Круг са мање од два узорка се одбија („holds no driving“).

## Грешке {#errors}

| Порука | Значење |
|---|---|
| `<file> is not a lap this can read. Give it a route or lap file (.json), a recording (.npz), a table with x, y and z columns (.csv), a folder of any of those, or just a course's name.` | фајл није JSON (и није `.npz` или `.csv`) |
| `<file> is JSON, but holds neither positions nor Lap.samples nor bounds` | JSON другог облика |
| `<file> has no x, y and z columns` | CSV без тих заглавља |
| `<file> has no positions array` | `.npz` без `positions` |
| `'<name>' is not a file, and there is no lap library at <path> to look it up in` | име, а нема библиотеке FH Companion-а |
| `'<name>' matches 3 courses: A, B, C` | будите конкретнији |
| `LOCALAPPDATA is not set, so the lap library cannot be found` | само за претрагу имена и `courses` |
