# Forza аутомобили: `cars` {#forza-cars-cars}

Записује сваки аутомобил инсталиране Forze на најнижем детаљу који даје сама игра у једну
датотеку за картицу Анализа трке у приказивачу (она црта по један аутомобил за сваки круг који си возио), тако да је сваки снимљени аутомобил нацртан у свом облику и у правој величини.

![cars --help](../assets/img/cars-help.svg)

## Корак по корак {#step-by-step}

1. **Покрени га** када је игра инсталирана (пронађе се у Steam библиотекама и у `C:\XboxGames`):

   ```
   python -m heat3d_gamefiles cars -o forza.h3dcars
   ```

   Или наведи фолдер игре:

   ```
   python -m heat3d_gamefiles cars --game "D:\Games\<Forza folder>" -o forza.h3dcars
   ```

2. **Учитај га у приказивач**: **Учитај датотеку са аутомобилима…** у подешавањима приказа, или превуци датотеку на картицу трке; остаје у том прегледачу. Кругови чији број аутомобила је у датотеци тада се црте као тај баш аутомобил (види [документацију о реприз трке у приказивачу](https://holdi601.github.io/3DHeat/race-replay-and-scene.html#the-cars)).

3. **Покрени га поново** када игра добије нове аутомобиле. Траје секунде и записује око 5 MB.

## Опције {#options}

| Опција | Подразумевано | Значење |
|---|---|---|
| `-o`, `--out FILE` | `./forza.h3dcars` | датотека која се записује |
| `--game FOLDER` | пронађена инсталирана игра | фолдер игре |

## Шта је у датотеци {#what-is-in-the-file}

За сваки архив аутомобила под `media/Cars`: `ProxyLOD` модел који носи (око 900 троуглова), број аутомобила онако како га телеметрија наводи, његов произвођач, ознака модела и година из имена архива, те његови точкови и задња светла. Облици су у метрима, 1:1 са аутомобилом. Архив без таквог модела (саобраћајни реквизит) се именује и изоставља.

Датотека је направљена за 3DHeat приказивач; њен распоред, за све који је читају на другом месту ([`forzacars.py`](https://github.com/Holdi601/3DHeat-GameFiles/blob/main/heat3d_gamefiles/forzacars.py)):

| Део | Распоред |
|---|---|
| цела датотека | компримована gzip-ом |
| магични бајтови | 8 бајтова `H3DCARS1` |
| дужина заглавља | little-endian u32 |
| заглавље | UTF-8 JSON: `format` (`heat3d-cars`), `version`, `game`, `source`, `cars` |
| попуна | размаци до умношка од 4 бајта |
| подаци | по аутомобилу: темена као три i16 сваки (милиметри; x десно, y горе, z напред), па троуглови као три u16 сваки |

Сваки унос у `cars`: `key`, `ordinals` (бројеви аутомобила онако како их телеметрија наводи), `make`, `model`, `year`, `height` и `length` (m), `wheels` (по точку `[x, y, z, radius]`, m), `lights` (тачке задњих светала `[x, y, z]`, m), и `vertexAt`, `vertices`, `faceAt`, `faces` (помаци у бајтовима од почетка података, и бројеви).

Датотека садржи игрину садржину: намењена је машини на којој је направљена, а не за слање даље ([Правила и лиценце](rules-and-licences.md)).
