# Unity: `SerializedFile`, bundles, meshes {#unity-serializedfile-bundles-meshes}

**Απαριθμεί αντικείμενα και αποκωδικοποιεί meshes** των αρχείων Unity `SerializedFile` format 22 και νεότερων (Unity 2020 έως 6000), και ανοίγει bundles `UnityFS`. Δεν υπάρχει εξαγωγή πίστας για Unity.

Πηγές: [`unity.py`](https://github.com/Holdi601/3DHeat-GameFiles/blob/main/heat3d_gamefiles/unity.py),
[`unity_mesh.py`](https://github.com/Holdi601/3DHeat-GameFiles/blob/main/heat3d_gamefiles/unity_mesh.py).
Εντολές: `identify` (containers και bundles), `meshes` (μόνο γυμνά containers).

## Το container {#the-container}

Η Unity κυκλοφορεί ένα επίπεδο ως σειριοποιημένα γραφήματα αντικειμένων: `globalgamemanagers`, `sharedassets*.assets`, `resources.assets`, `level*`, και bundles με assets. Καθένα κρατά έναν πίνακα αντικειμένων με ετικέτα κλάσης.

Η κεφαλίδα είναι το σημείο όπου η ανάγνωση πάει στραβά χωρίς να φαίνεται. Τα πρώτα δεκάξι bytes είναι τέσσερις `uint32` big-endian που κρατιούνται για συμβατότητα. Στη μορφή 22, τρεις από αυτές είναι μηδέν, και οι πραγματικές τιμές ακολουθούν, επειδή ένα αρχείο μπορεί να ξεπερνά τα 4 GB:

```
[legacy metadata size : 4] [legacy file size : 4] [format version : 4] [legacy data offset : 4]
[endianness : 1] [reserved : 3]
[metadata size : 4] [file size : 8] [data offset : 8] [unknown : 8]
```

Το δεύτερο `metadata size` είναι `uint32` ανάμεσα σε δύο `int64`. Αν υποθέσει κανείς ότι και οι τρεις είναι 64-bit, η συμβολοσειρά έκδοσης μετατοπίζεται κατά τέσσερα bytes. Εξακολουθεί να αποκωδικοποιείται σε κάτι που μοιάζει με συμβολοσειρά, και στέλνει όλα όσα ακολουθούν λάθος. Η κεφαλίδα είναι big-endian. Όλα τα υπόλοιπα ακολουθούν το byte της ενδιάθεσης (0, little-endian, σε κάθε desktop build).

Μετά την κεφαλίδα: η συμβολοσειρά έκδοσης της μηχανής, η πλατφόρμα, η σημαία του type tree, ο πίνακας τύπων (ταυτότητα κλάσης ανά τύπο), ο πίνακας αντικειμένων (path id, offset, μέγεθος, τύπος), και τα εξωτερικά (άλλα αρχεία στα οποία μπορεί να δείχνει ένας δείκτης).

| Περίπτωση | Αποτέλεσμα |
|---|---|
| format 22-30 | διαβάζεται |
| format 9-21 (πριν το Unity 2020) | αρνείται: τα offsets είναι στην παλαιά κεφαλίδα, και κανένα αρχείο που είχαμε δεν τη χρησιμοποιούσε |
| έξω από το 9-30 | αρνείται |
| ενσωματωμένο type tree (builds του επεξεργαστή) | αρνείται: τα shipped builds δεν έχουν ενσωματωμένο, και η διαδρομή του επεξεργαστή δεν υλοποιείται |
| bundle όπου αναμένεται container | αρνείται, με παραπομπή στον αναγνώστη bundles |

Δεν υπάρχει **γενικός αποσειριοποιητής**. Τα shipped builds δεν φέρουν type tree, επειδή το σχήμα είναι μεταγλωττισμένο μέσα στον player, οπότε κάθε κλάση πρέπει να αναλύεται έναντι διάταξης γνωστής για την έκδοσή της. Αποκωδικοποιείται μόνο το `Mesh`. Οι άλλες κλάσεις αναφέρονται με όνομα και πλήθος (`GameObject`, `Transform`, `MeshRenderer`, `MeshFilter`, `Mesh`, `BoxCollider`, `MeshCollider`, `MonoBehaviour`, `MonoScript`, `AssetBundle`, `RectTransform`, `PrefabInstance`· οι υπόλοιπες ως `class<id>`).

**Επαληθεύτηκε** σε πολλά εγκατεστημένα παιχνίδια και εκατομμύρια αντικείμενα: ο πίνακας αντικειμένων πρέπει να καλύπτει το τμήμα δεδομένων ακριβώς, χωρίς επικαλύψεις, χωρίς τίποτα άλλο πέρα από padding ευθυγράμμισης ανάμεσα στα αντικείμενα, και το τελευταίο αντικείμενο να τελειώνει στο τελευταίο byte του αρχείου. Ένα λάθος διαβασμένη κεφαλίδα δεν μπορεί να το παράγει. Το τεστ εγκατεστημένου παιχνιδιού το επαναλαμβάνει σε έως έξι αρχεία `resources.assets` / `sharedassets0.assets` που βρίσκονται σε φακέλους `*_Data`.

## Bundles (`UnityFS`) {#bundles-unityfs}

Ένα bundle είναι ένα συμπιεσμένο container από αρχεία SerializedFile. Η λίστα μπλοκ και ο κατάλογος είναι επίσης συμπιεσμένα. Η μέθοδος βρίσκεται στα χαμηλά έξι bits μιας λέξης σημαιών: 0 αποθηκευμένο, 1 LZMA (η κεφαλίδα 5 bytes της Unity με το μέγεθος ενσωματωμένο), 2 και 3 LZ4 / LZ4HC. Η μορφή 7 και νεότερες ευθυγραμμίζουν την κεφαλίδα σε 16 bytes. Η σημαία `0x80` βάζει τον κατάλογο στο τέλος του αρχείου. Τα `UnityWeb`, `UnityRaw` και `UnityArchive` (πριν το 5.3) αναγνωρίζονται αλλά δεν διαβάζονται.

## Meshes {#meshes}

Το `read_mesh` αποκωδικοποιεί ένα αντικείμενο `Mesh` σε θέσεις, καθέτους, το πρώτο σύνολο UV και τρίγωνα, με τη σειρά που γράφει η Unity 2019 και νεότερες: όνομα, submeshes, blend shapes (παρακάμπτονται), bind poses και δεδομένα οστών (παρακάμπτονται), οι σημαίες συμπίεσης και αναγνωσιμότητας, το buffer δεικτών, τα κανάλια κορυφών και τα δεδομένα κορυφών, το συμπιεσμένο μπλοκ mesh, το τοπικό bounding box, και οι πληροφορίες ροής.

- **Εξωτερικές κορυφές.** Τα περισσότερα shipped γεωμετρικά δεδομένα ζουν σε ένα αρχείο `.resS` δίπλα στο container. Το εργαλείο το διαβάζει από τον φάκελο του container (χρησιμοποιείται μόνο το όνομα αρχείου της αποθηκευμένης διαδρομής `archive:/...`). Ένα `.resS` που λείπει είναι σφάλμα, όχι κενό mesh.
- **Ροές και κανάλια.** Τα κανάλια λένε ποια ροή, offset, μορφή και διάσταση έχει κάθε χαρακτηριστικό. Οι ροές τοποθετούνται η μία μετά την άλλη, καθεμία συμπληρωμένη σε 16 bytes, οπότε η αρχή μιας ροής αθροίζεται από τα strides που προηγούνται. Μορφές: float32, float16, unorm/snorm 8 και 16 (κανονικοποιημένες), και απλοί ακέραιοι.
- **Τοπολογία.** Μόνο τρίγωνα (topology 0). Λωρίδες, τετράπλευρα και γραμμές αρνούνται, επειδή μια λάθος μετατροπή μοιάζει με πραγματική γεωμετρία.
- **Συμπιεσμένα meshes** (κβαντισμένες διαφορές) αρνούνται: `mesh '...' is stored compressed; that encoding is not implemented`.

### Ο αυτοέλεγχος {#the-self-check}

Η ανάγνωση μιας δομής με λάθος σειρά δεν δίνει σφάλμα. Δίνει λογικούς αριθμούς. Γι' αυτό κάθε αποκωδικοποιημένο mesh ελέγχεται έναντι του **bounding box που έχει αποθηκεύσει η Unity για αυτό**, που το υπολόγισε ο επεξεργαστής από τις πραγματικές κορυφές. Το `aabb_matches()` περνά όταν οι γωνίες του αποκωδικοποιημένου κουτιού βρίσκονται εντός 2% του μεγέθους του αποθηκευμένου κουτιού. Το `meshes` τυπώνει `ok` ή `BOUNDS DISAGREE` σε κάθε γραμμή.

**Επαληθεύτηκε:** τα meshes που δειγματίστηκαν από αρκετά παιχνίδια αποκωδικοποιούνται και τα όριά τους συμφωνούν. Το τεστ εγκατεστημένου παιχνιδιού επαναλαμβάνει τον έλεγχο στα εγκατεστημένα containers.

## Δεν υλοποιείται {#not-implemented}

- Μορφές πριν το 2020.
- Συμπιεσμένα meshes.
- Κάθε κλάση εκτός από το `Mesh`: χωρίς γράφημα σκηνής, μετασχηματισμούς ή υλικά, οπότε τα meshes είναι στον δικό τους τοπικό χώρο.
- `meshes` σε bundle. Ο αναγνώστης bundles υπάρχει στην Python (`UnityBundle.serialized_files()`), αλλά η εντολή δέχεται μόνο γυμνό container.
