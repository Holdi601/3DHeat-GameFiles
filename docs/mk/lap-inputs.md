# Влезови за круг {#lap-inputs}

**Датотека на круг** е листа од точки x, y, z: каде отишол автомобилот. Најбрзата
рачно направена е CSV-то подолу во [5. Табела `.csv`](#a-csv-table).

Кругот му кажува на извозот на патека **каде отишол автомобилот**. Ништо друго од него
не се користи: брзината, командите и g-силите припаѓаат на страната на телеметријата во
3DHeat. Алатката чита позиции во сопствените светски метри на играта, плус, кога
датотеката го кажува тоа, играта и патеката.

Извор: [`lapinput.py`](https://github.com/Holdi601/3DHeat-GameFiles/blob/main/heat3d_gamefiles/lapinput.py).

## Што прифаќа `course` {#what-course-accepts}

Форматот се препознава според самата датотека, а не според името, освен што `.npz` и
`.csv` одат по наставка, а сè друго се пробува како JSON.

### 1. Документ `heat3d-lap` (која било игра) {#a-heat3d-lap-document-any-game}

Го пишуваат снимачите на телеметрија на 3DHeat (`heat3d_capture telemetry` ([3DHeat GameCapture](https://github.com/Holdi601/3DHeat-GameCapture))):

```json
{
  "format": "heat3d-lap",
  "game": "beamng",
  "track": "Example Stage",
  "channels": {
    "x": [12.0, 12.4, 12.9],
    "y": [3.1, 3.1, 3.2],
    "z": [-40.0, -38.7, -37.3],
    "speed": [21.0, 21.3, 21.8]
  }
}
```

- `channels.x`, `channels.y`, `channels.z` се задолжителни. Редовите каде кој било од
  трите не е конечен број се отфрлаат. Другите канали се игнорираат.
- `game` го одредува извозот (видете [Команди](commands.md#which-game)).
- `track` го користи Assetto Corsa Rally за прво да ја пробува именуваната етапа.
- Оски: y е висина. Круговите на Forza и AC Rally ги користат хоризонталните оски на
  играта како што ги пишува снимачот. Круговите на BeamNG се очекуваат во рамката на
  прегледувачот, `(x, z, -y)` од светот на BeamNG со Z нагоре (видете
  [BeamNG.drive](course-beamng.md#the-laps-frame)).

### 2. Датотека на рута {#a-route-file}

Ја пишуваат `heat3d_capture route` и `heat3d_capture laps`:

```json
{
  "bounds": {"min": [0.0, 80.0, 0.0], "max": [500.0, 140.0, 500.0]},
  "positions": [[12.0, 101.2, 40.5], [12.9, 101.2, 42.0]]
}
```

`positions` е листа од `[x, y, z]`. Датотека на рута со `bounds` но без позиции
и понатаму работи: нејзините два агли се дегенерирана линија, но употреблива кутија.

### 3. Датотека на круг од FH Companion {#an-fh-companion-lap-file}

Датотеките по круг од снимената библиотека на FH Companion:

```json
{"Lap": {"samples": [{"X": 12.0, "Y": 101.2, "Z": 40.5}, {"X": 12.9, "Y": 101.2, "Z": 42.0}]}}
```

Недостасувачко `X`, `Y` или `Z` се чита како 0. Датотеките се пишуваат со ознака за
редослед на бајти (BOM), па целиот JSON се чита како `utf-8-sig`.

### 4. Снимка `.npz` {#a-npz-recording}

NumPy архива што содржи низа `positions` со облик (n, 3).

### 5. Табела `.csv` {#a-csv-table}

```
# {"game": "assetto-corsa-rally", "track": "Example Stage"}
time,x,y,z,speed
0.00,12.0,3.1,-40.0,21.0
0.05,12.4,3.1,-38.7,21.3
```

- Колоните со име `x`, `y`, `z` (големи и мали букви и околните празни места се
  игнорираат) се задолжителни. Другите колони се игнорираат.
- Линиите што почнуваат со `#` се прескокнуваат. Ако **првата** линија е `# {json}`,
  се читаат нејзините `game` и `track`.
- Редовите што не се парсираат како броеви се прескокнуваат.

### 6. Папка {#a-folder}

Папката се пребарува **рекурзивно** за датотеки `.json`, `.npz` и `.csv`, и сите се
спојуваат во една возена линија. Така се чува цела снимена патека: FH Companion
вгнездува папки за класа, автомобил, подесување и ознака.

- `course.json` се прескокнува по име (тоа се метаподатоци, а не круг).
- Датотека што не се чита се прескокнува тивко. Една лоша датотека меѓу стотици не го
  чини остатокот.
- Конзолата пријавува колку датотеки на кругови влегле (`12 laps, 18,400 samples`).
- Папката ја добива играта што ја именуваат нејзините датотеки, кога именуваат **само
  една**. Датотека што не именува игра (круг од FH Companion, `course.json`, CSV без
  линија со опис) не се брои, па една таква меѓу снимките на една игра не ја чини
  папката нејзината игра. Датотеки што именуваат две различни игри се мешавина, а
  папката не добива ниту една. Папка без игра се извезува како Forza освен ако `--game`
  не каже поинаку.
- Ако ништо не се чита: „no readable laps under <folder>“.

### 7. Име на патека {#a-course-name}

Ако аргументот не е постоечка датотека или папка, се бара како име на патека во
библиотеката на FH Companion, `%LOCALAPPDATA%\FHCompanion\laps`:

1. папка чие име, со отстранет суфикс ` (course_...)`, е еднакво на името (без разлика
   на големи и мали букви);
2. инаку единствената папка чие име го содржи.

Така `"Example Circuit"` наоѓа
`Example Circuit (course_1200_3400_to_1175_3400)` без никој да ги знае координатите.
Повеќе совпаѓања се грешка што ги наведува. Патека најдена по име не носи игра, па се
извезува како Forza освен ако `--game` не каже поинаку.

## Што прифаќа `terrain --route` {#what-terrain---route-accepts}

`terrain` ги бара `bounds` на датотеката на рутата (облик 2 погоре),
`{"min": [x, y, z], "max": [x, y, z]}`. Без `bounds`, запира со
„<file> has no bounds; --route takes a route file with "bounds": {...}“. Датотеката се
чита како UTF-8 со или без ознака за редослед на бајти, како секој JSON на круг. Ако истата
датотека има и најмалку 10 позиции читливи според правилата погоре, тие го стеснуваат
исечокот на коридор и го насочуваат детаљот.

## Како се користи кругот {#how-the-lap-is-used}

| Употреба | Детал |
|---|---|
| име | стеблото на датотеката, или името на папката, со отстрането ` (course_...)`; станува стандардно име на излезната датотека |
| поминато растојание | збирот на растојанијата меѓу последователни примероци (се печати како `m driven`; низ папка ова ги вклучува скоковите меѓу датотеките) |
| кутија | опсегот на x и z проширен со `--margin`; висината никогаш не е ограничена |
| коридор | x и z на секој примерок, видете [Извоз на патека](course-export.md#the-corridor) |
| детал | растојанието на секоја поставена копија до најблискиот примерок, видете [Нивоа на детали и буџетот](detail-budget.md) |

Круг со помалку од два примероци се одбива („holds no driving“).

## Грешки {#errors}

| Порака | Значење |
|---|---|
| `<file> is not a lap this can read. Give it a route or lap file (.json), a recording (.npz), a table with x, y and z columns (.csv), a folder of any of those, or just a course's name.` | датотеката не е JSON (и не е `.npz` или `.csv`) |
| `<file> is JSON, but holds neither positions nor Lap.samples nor bounds` | JSON со друг облик |
| `<file> has no x, y and z columns` | CSV без тие заглавија |
| `<file> has no positions array` | `.npz` без `positions` |
| `'<name>' is not a file, and there is no lap library at <path> to look it up in` | име, но нема библиотека на FH Companion |
| `'<name>' matches 3 courses: A, B, C` | бидете поконкретни |
| `LOCALAPPDATA is not set, so the lap library cannot be found` | само за барање по име и `courses` |
