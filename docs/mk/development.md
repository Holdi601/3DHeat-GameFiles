# Развој {#development}

## Распоред {#layout}

```
heat3d_gamefiles/     the package: readers, course exports, the command line
heat3d_update/        the release check and updater (see Updates)
tests/                synthetic tests, fixtures, and tests against installed games
docs/                 this documentation (docs/wiki is generated from it)
VERSION               the installed version, compared with GitHub releases
requirements.txt      numpy, cryptography, lz4, Pillow, msgpack, zstandard, pytest
```

## Пуштање на тестовите {#running-the-tests}

```
pip install -r requirements.txt
python -m pytest
```

`pytest.ini` поставува `testpaths = tests` и `-q`. Два вида тестови се важни, од
различни причини:

- **Синтетичките тестови** градат архиви бајт по бајт и работат насекаде. Ги фиксираат
  распоредите на полињата што во некој момент биле погрешни: 64-битната основа на
  сегмент во `.minizip` и нејзиното дополнување за порамнување, излезот за големина на
  блок во pak, u32 во заглавието на Unity меѓу два int64, индексот `0x7FFF` на VPK,
  поделеното x на нормалата на Forza.
- **Тестовите на инсталирана игра** работат спрема вистинските датотеки кога играта е на
  машината, и **се прескокнуваат** (не паѓаат) кога не е. Тие се единственото што фаќа
  распоред што е правилен за мала датотека а погрешен за голема.

## Тестови на инсталирана игра {#installed-game-tests}

[`tests/installed.py`](https://github.com/Holdi601/3DHeat-GameFiles/blob/main/tests/installed.py)
ги наоѓа игрите за тестовите. `steam_common()` го наведува `steamapps\common` на секоја
Steam библиотека (вклучувајќи ги и сопствените папки на Steam), а `installed(*globs)`
ги враќа патеките што се совпаѓаат со кој било glob под нив, рекурзивно каде glob има
`**`. Секој тест одлучува што му треба:

| Тест | Бара | Се прескокнува со |
|---|---|---|
| `test_pak.py` | `*/(*/){0..3}Content/Paks/*.pak` со **нешифриран** индекс, до 4 | „no shipped pak on this machine“ |
| `test_unity.py` | `resources.assets` / `sharedassets0.assets` во `*/*_Data` или `*/*/*_Data` што читачот ги прифаќа, до 6 | „no Unity game on this machine“ |
| `test_frostbite.py` | `Battlefield*/**/*.toc` | „no Frostbite game on this machine“ |
| `test_frostbitelevel.py` | `Battlefield*/**/levels/**/*.toc` | „no Frostbite level on this machine“ |
| `test_vpk.py` | `Counter-Strike Global Offensive/game/csgo/maps/*.vpk`, до 6 | „Counter-Strike 2 is not installed“ |
| `test_forzatech.py` | `ForzaHorizon*/media/*.zip` | „no Forza install on this machine“ |
| `test_forzaplacement.py` | патеките од библиотеката на FH Companion (почеток и крај во рамки на 50 m), со најмногу кругови, што `find_track` ги поставува; или `HEAT3D_COURSE` | „no Forza install with a recorded lap library here“ |
| `test_beamng.py` | `find_install()` | „BeamNG.drive is not installed“ |
| `test_acrally.py` | `find_paks()` | „Assetto Corsa Rally is not installed“ |

Пуштете само тестови за една игра, или насочете го тестот за рабници на Forza кон
патека:

```
python -m pytest tests/test_vpk.py
set HEAT3D_COURSE=%LOCALAPPDATA%\FHCompanion\laps\Example Circuit (course_0_0_to_0_0)
python -m pytest tests/test_forzaplacement.py -k kerbs
```

Тестовите на инсталирана игра читаат само од игрите. Не пишуваат ништо во папките на
играта. Излезите од тестовите одат во привремените папки на pytest.

## Конвенции {#conventions}

- **Одбиј, не погодувај.** Секој читач дава свој исклучок
  (`UnsupportedPak`, `IoStoreError`, `UnsupportedForza`, `UnsupportedUnity`,
  `UnsupportedFrostbite`, `UnsupportedVpk`, `BeamNGError`, `PropertyError`...) со порака
  што кажува што е најдено и зошто не е прочитано.
- **Проверка спрема самиот формат.** Хеш, CRC, синџир од поместувања, зачувана рамка за
  ограничување, возењето што лежи на земјата. Не „не падна“.
- **Без клучеви, без пакуван проприетарен код.** Видете [Правила и лиценци](rules-and-licences.md).
- **Доверливите податоци остануваат надвор.** Датотеки на игри, извози, кругови, снимки
  и слики од екран никогаш не одат во складиштето. `.gitignore` ги исклучува по папка
  и по тип. Тестовите користат синтетички податоци и инсталирани игри, никогаш
  проверена содржина на игри.
