# Входни данни за обиколка {#lap-inputs}

**Файл с обиколка** е списък от точки x, y, z: къде е отишла колата ви. Най-бързият ръчно направен е CSV файлът от [5. Таблица `.csv`](#5-таблица-csv) по-долу.

Обиколката казва на експорта на трасе **къде е отишла колата**. Нищо друго в нея не се използва: скоростта, управлението и g-силите принадлежат на телеметричната част на 3DHeat. Инструментът чете позиции в световните метри на играта, а където файлът го казва — играта и трасето.

Източник: [`lapinput.py`](https://github.com/Holdi601/3DHeat-GameFiles/blob/main/heat3d_gamefiles/lapinput.py).

## Какво приема `course` {#what-course-accepts}

Форматът се разпознава по съдържанието на файла, а не по името му, освен че `.npz` и `.csv` се разпознават по разширението. Всичко друго се пробва като JSON.

### 1. Документ `heat3d-lap` (всяка игра) {#a-heat3d-lap-document-any-game}

Записва се от телеметричните записвачи на 3DHeat (`heat3d_capture telemetry` ([3DHeat GameCapture](https://github.com/Holdi601/3DHeat-GameCapture))):

```json
{
  "format": "heat3d-lap",
  "game": "beamng",
  "track": "Example Stage",
  "channels": {
    "x": [12.0, 12.4, 12.9],
    "y": [3.1, 3.1, 3.2],
    "z": [-40.0, -38.7, -37.3],
    "speed": [21.0, 21.3, 21.8]
  }
}
```

- `channels.x`, `channels.y`, `channels.z` са задължителни. Редовете, в които някой от трите не е краен номер, се отхвърлят. Другите канали се пренебрегват.
- `game` определя експорта (вижте [Команди](commands.md#which-game)).
- `track` се използва от Assetto Corsa Rally, за да пробва първо посочения етап.
- Оси: y е височината. Обиколките на Forza и AC Rally ползват хоризонталните оси на играта така, както ги записва записвачът. Обиколките на BeamNG се очакват в рамката на визуализатора, `(x, z, -y)` от света на BeamNG с Z нагоре (вижте [BeamNG.drive](course-beamng.md#the-laps-frame)).

### 2. Файл с маршрут {#a-route-file}

Записва се от `heat3d_capture route` и `heat3d_capture laps`:

```json
{
  "bounds": {"min": [0.0, 80.0, 0.0], "max": [500.0, 140.0, 500.0]},
  "positions": [[12.0, 101.2, 40.5], [12.9, 101.2, 42.0]]
}
```

`positions` е списък от `[x, y, z]`. Файл с маршрут с `bounds`, но без позиции, пак работи: двата му ъгъла са изроден ред, но използваема кутия.

### 3. Файл с обиколка от FH Companion {#an-fh-companion-lap-file}

Отделните файлове с обиколки от записаната библиотека на FH Companion:

```json
{"Lap": {"samples": [{"X": 12.0, "Y": 101.2, "Z": 40.5}, {"X": 12.9, "Y": 101.2, "Z": 42.0}]}}
```

Липсващо `X`, `Y` или `Z` се чете като 0. Файловете са записани с маркер за ред на байтовете, затова целият JSON се чете като `utf-8-sig`.

### 4. Запис `.npz` {#a-npz-recording}

Архив на NumPy с масив `positions` с форма (n, 3).

### 5. Таблица `.csv` {#a-csv-table}

```
# {"game": "assetto-corsa-rally", "track": "Example Stage"}
time,x,y,z,speed
0.00,12.0,3.1,-40.0,21.0
0.05,12.4,3.1,-38.7,21.3
```

- Колоните `x`, `y`, `z` (без значение на главни букви и празни места около името) са задължителни. Другите колони се пренебрегват.
- Редовете, които започват с `#`, се пропускат. Ако **първият** ред е `# {json}`, от него се четат `game` и `track`.
- Редовете, които не се четат като числа, се пропускат.

### 6. Папка {#a-folder}

Папката се претърсва **рекурсивно** за файлове `.json`, `.npz` и `.csv`, и всички се слепват в една шофирана линия. Така се пази цяло записано трасе: FH Companion влага папки по клас, кола, настройка и етикет.

- `course.json` се пропуска по име (това е метаинформация, а не обиколка).
- Файл, който не се чете, се пропуска тихо. Един лош файл сред стотици не отнема останалите.
- Конзолата докладва колко файла с обиколки са влезли (`12 laps, 18,400 samples`).
- Папката получава играта, която файловете ѝ назовават, когато назовават **само една**. Файл, който не назовава игра (обиколка от FH Companion, `course.json`, CSV без ред с описание), не се брои, така че един такъв сред записите на една игра не отнема на папката играта ѝ. Файлове, които назовават две различни игри, са смесица и папката не получава никоя. Папка без игра се експортира като Forza, освен ако `--game` не казва друго.
- Ако нищо не се прочете: „no readable laps under <folder>“.

### 7. Име на трасе {#a-course-name}

Ако аргументът не е съществуващ файл или папка, той се търси като име на трасе в библиотеката на FH Companion, `%LOCALAPPDATA%\FHCompanion\laps`:

1. папка, чието име, без суфикса ` (course_...)`, е равно на търсеното (без значение на главни и малки букви);
2. иначе единствената папка, чието име съдържа търсеното.

Така `"Example Circuit"` намира `Example Circuit (course_1200_3400_to_1175_3400)`, без някой да знае координатите. Няколко съвпадения са грешка, която ги изброява. Трасе, намерено по име, не носи игра, затова се експортира като Forza, освен ако `--game` не казва друго.

## Какво приема `terrain --route` {#what-terrain---route-accepts}

`terrain` се нуждае от `bounds` на файла с маршрут (форма 2 по-горе), `{"min": [x, y, z], "max": [x, y, z]}`. Без `bounds` спира с „<file> has no bounds; --route takes a route file with "bounds": {...}“. Файлът се чете като UTF-8 с или без маркер за ред на байтовете, както всеки JSON от обиколка. Ако същият файл има и поне 10 позиции, които се четат по правилата по-горе, те стесняват изрязването до коридор и насочват детайла.

## Как се ползва обиколката {#how-the-lap-is-used}

| Употреба | Подробности |
|---|---|
| име | основата на името на файла или името на папката, без ` (course_...)`; става името по подразбиране на изходния файл |
| изминато разстояние | сборът от разстоянията между съседни точки (извежда се като `m driven`; при папка включва скоковете между файловете) |
| кутия | обхватът по x и z, разширен с `--margin`; височината никога не се ограничава |
| коридор | x и z на всяка точка, вижте [Експорт на трасе](course-export.md#the-corridor) |
| детайл | разстоянието на всяко разположено копие до най-близката точка, вижте [Нива на детайл и бюджетът](detail-budget.md) |

Обиколка с по-малко от две точки се отхвърля („holds no driving“).

## Грешки {#errors}

| Съобщение | Значение |
|---|---|
| `<file> is not a lap this can read. Give it a route or lap file (.json), a recording (.npz), a table with x, y and z columns (.csv), a folder of any of those, or just a course's name.` | файлът не е JSON (нито `.npz`, нито `.csv`) |
| `<file> is JSON, but holds neither positions nor Lap.samples nor bounds` | JSON с друга форма |
| `<file> has no x, y and z columns` | CSV без тези заглавия |
| `<file> has no positions array` | `.npz` без `positions` |
| `'<name>' is not a file, and there is no lap library at <path> to look it up in` | име, но няма библиотека на FH Companion |
| `'<name>' matches 3 courses: A, B, C` | бъдете по-точен |
| `LOCALAPPDATA is not set, so the lap library cannot be found` | само за търсене по име и за `courses` |
